# BooksCollector - Тесты

Проект содержит полное покрытие тестами класса BooksCollector, который позволяет управлять коллекцией книг, устанавливать жанры и добавлять книги в избранное.

## Реализованные тесты

### 1. test_add_new_book_name_length
Параметризованный тест для проверки добавления книг с разной длиной названия:
- Книга с нормальным названием (добавляется успешно)
- Книга с названием длиннее 40 символов (не добавляется)
- Книга с пустым названием (не добавляется)

### 2. test_add_new_book_add_two_books
Проверяет добавление двух книг в коллекцию.

### 3. test_set_book_genre
Параметризованный тест для установки жанра книги:
- Установка валидного жанра для существующей книги
- Установка жанра для несуществующей книги
- Установка несуществующего жанра

### 4. test_get_book_genre
Проверяет получение жанра книги по её имени:
- Получение жанра существующей книги
- Получение жанра несуществующей книги (возвращает None)

### 5. test_get_books_with_specific_genre
Проверяет получение списка книг с определённым жанром:
- Получение списка книг с валидным жанром
- Получение списка книг с несуществующим жанром (возвращает пустой список)

### 6. test_get_books_genre
Проверяет получение всего словаря books_genre.

### 7. test_get_books_for_children
Проверяет получение книг, подходящих детям (без возрастного рейтинга):
- Книги с жанрами "Фантастика" и "Мультфильмы" включаются
- Книги с жанрами "Ужасы" и "Детективы" исключаются

### 8. test_add_book_in_favorites
Проверяет добавление книги в избранное:
- Добавление существующей книги
- Попытка добавить несуществующую книгу
- Повторное добавление той же книги (не должно дублироваться)

### 9. test_delete_book_from_favorites
Проверяет удаление книги из избранного:
- Удаление существующей книги из избранного
- Попытка удалить несуществующую книгу

### 10. test_get_list_of_favorites_books
Проверяет получение списка избранных книг.

## Запуск тестов

Для запуска всех тестов с подробным выводом результатов выполните команду:

```bash
pytest -v tests.py
